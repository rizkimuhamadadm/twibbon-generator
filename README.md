# Twibbon Generator

Aplikasi web ringan, modern, dan sumber terbuka (open-source) yang dirancang untuk memudahkan pengguna memasukkan foto ke dalam bingkai kustom serta mengunduh hasilnya dengan kualitas tinggi.

Dibuat oleh Adam.

---

## Fitur Utama

- **Geser dan Atur Posisi:** Klik dan tahan foto untuk menggeser serta menyesuaikan posisinya di dalam bingkai.
- **Pengaturan Skala (Zoom):** Sesuaikan ukuran foto menggunakan tombol, slider, maupun scroll pada mouse.
- **Hasil Kualitas Tinggi:** Menggunakan library HTML2Canvas dengan skala 3x agar gambar yang diunduh tetap tajam (Format PNG).
- **Dukungan Layar Sentuh:** Kompatibel penuh untuk digunakan di perangkat seluler dan tablet.
- **Antarmuka Modern:** Dirancang menggunakan Tailwind CSS dengan tampilan tema gelap yang bersih.

---

## Teknologi yang Digunakan

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- HTML2Canvas
